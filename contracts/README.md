# 机器可读契约

契约按能力域编号，编号与 `docs/` 中的交付模块保持一致。

- `01-capabilities/`：统一 Capability Catalog 与 Manifest Schema。
- `02-agent-pack/`：Agent Pack 导入格式。
- `03-realtime-transcription/`：实时转写 WebSocket 消息协议。
- `04-interoperability/`：REST/OpenAPI、A2A 与 MCP 示例。
- `05-design-system/`：可导入设计令牌与预设主题。
- `05-models/`：工作区模型配置与视觉能力声明。

修改 Schema 时同步更新对应示例、文档与契约测试。
